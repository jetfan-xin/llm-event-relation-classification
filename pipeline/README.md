# Seminar pipeline source code

This directory contains the seminar's complete unique Python implementation and exploration notebook. It is the source of the project's collection, prompting, generation, evaluation and visualization work, not a selection of unused examples. Byte-identical copies from the two supplied source folders are consolidated; the [source manifest](../source-manifest.json) maps every source file, including duplicate locations, to its published implementation.

## Implementation map

| Component | Source | Role |
| --- | --- | --- |
| Collection | [data_collector.py](data_collector.py) | Paginates ConceptNet relations and extracts event pairs and assertion text. |
| Prompt design | [prompt_library.py](prompt_library.py) | Defines the four relations, examples and structured-response prompts. Also imported directly by the runnable `event_relations` package. |
| LLM generation | [generator.py](generator.py) | Implements three-response sampling, voting, tie-breaking, progress loading and output saving. |
| Evaluation | [evaluator.py](evaluator.py) | Computes per-relation metrics, first-response comparisons and confusion-matrix plots. |
| Graph analysis | [visualizer.py](visualizer.py) | Builds connected-event graphs, extracts a k-core and filters neighborhoods for interactive visualization. |
| Reference-label graph variant | [visualizer_all_associated_kcore_simplified.py](visualizer_all_associated_kcore_simplified.py) | Retains the expanded implementation using reference relations for edge coloring. |
| Prediction-label graph variant | [visualizer_all_associated_kcore_simplified_generated.py](visualizer_all_associated_kcore_simplified_generated.py) | Retains the expanded implementation using generated relation labels for edge coloring. |
| Error filtering | [filter.py](filter.py) | Extracts predictions with the exact label `/r/HasSubevent`. |
| Assertion-text enrichment | [merge.py](merge.py) | Joins the selected records with original assertion text. |
| Qualitative sampling | [random_filter.py](random_filter.py) | Samples up to 10 records from each of three targeted reference relations. |
| Error inspection | [analyzer.py](analyzer.py) | Prints event pairs, predicted and reference relations, model explanations and assertion text. |

The [exploration directory](exploration) also retains the early collector, WordNet topic-selection notebook, small illustrative graph and local file-listing utility. These are included for source completeness, not represented as additional evaluated models.

## Run the project

From the repository root, the tested command-line interface runs evaluation and graph analysis without an API key or third-party dependencies:

```bash
python3 -B -m event_relations evaluate data/predictions.json
python3 -B -m event_relations graph data/predictions.json --labels selected --k 2 --hops 2
```

To run the original qualitative-error analyzer directly against its saved input:

```bash
cd artifacts/original/semantic-networks_total/data
python3 -B ../../../../pipeline/analyzer.py
```

For collection, resumable model generation and optional interactive export, use the [running guide](../docs/usage.md). The runnable modules are in [event_relations](../event_relations); the [method notes](../docs/method.md) document their validation and algorithm changes. They do not claim the saved experiment outputs were generated by a different implementation.

## Source compatibility

The original scripts retain their original relative paths and execution behavior. Several load data, write files or open plots at import time, so import only modules intended as libraries. The original collector appends JSON, and the generator's bottom-level statement prints a prompt rather than calling its batch method. Its embedded credential is replaced with `xxx`; the recorded endpoint is retained only as source context. Use explicit configuration and the bounded CLI for fresh model requests.

Original results, including known errors, are preserved in the [workflow and output catalog](../artifacts/README.md). No experiment was rerun to replace them. The source code is byte-identical to the supplied files except for the generator's credential replacement, string quoting and final newline; its parsed syntax tree otherwise matches the source. Original comments remain, while repository guides are in English.
